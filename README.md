⚙️ **How Aimbot Works**

Aimbot Script works by sending optimized controller inputs through your Cronus Zen while you play Fortnite. The script continuously monitors ADS activation, stick movement, and trigger pressure to determine when to activate its aim assist systems.

The profile uses two synchronized systems:

### **AA_XY Oscillation**

While ADS is held:

* RY oscillates between +22 and -22
* RX oscillates between +22 and -22
* LX oscillates simultaneously
* Each movement step runs at 20ms intervals

Before applying any oscillation, the script checks the current stick position using the release threshold system:

* If stick movement exceeds the threshold value (default 25), your real input passes through untouched
* If stick movement remains below the threshold, oscillation activates normally

This prevents the script from interfering with deliberate aiming adjustments.

### **AIM_ABUSE ADS Spam**

When ADS pressure exceeds 95%:

* ADS holds for 320ms
* ADS releases for 30ms
* The cycle repeats continuously while ADS remains active

Both systems run simultaneously whenever SensitiveAbuse is enabled.

Pressing D-Pad Left instantly toggles all systems on or off during gameplay.
